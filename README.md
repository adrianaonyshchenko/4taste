# 4taste

## Опис
4taste- кулінарний щоденник, застосунок для зберігання, перегляду та організації рецептів.
Користувач може додавати власні рецепти, ділити їх по категоріях, підбирати страви на основі наявних продуктів тощо

## Призначення
Зручний застосунок для збереження та організації кулінарних рецептів, що дозволяє користувачам швидко знаходити необхідні 
страви та вести власну колекцію рецептів.
