# 4taste

## Опис
4taste- кулінарний щоденник, застосунок для зберігання, перегляду та організації рецептів.
Користувач може додавати власні рецепти, ділити їх по категоріях, підбирати страви на основі наявних продуктів тощо

## Проблема
Сучасним користувачам часто важко швидко знайти оригінальні чи збалансовані рецепти під конкретні інгредієнти, які є в холодильнику, або зручно структурувати власну кулінарну книгу та планувати своє харчування в одному настільному застосунку.

## Цільові користувачі
* Любителі готувати, які шукають нові ідеї для щоденного меню.
* Початківці в кулінарії, яким потрібні покрокові інструкції та чіткі дозування.
* Люди, які ведуть облік харчування або шукають рецепти за певними категоріями.

##  Мета проєкту
Створити зручний та функціональний настільний застосунок на платформі .NET (Windows Forms / WPF) для пошуку, збереження, фільтрації та управління кулінарними рецептами.

## Основні можливості 
* Каталог рецептів із можливістю пошуку та фільтрації (за категоріями, інгредієнтами тощо).
* Детальний перегляд рецепта (складники, покроковий опис приготування, час).
* Можливість додавання, редагування та видалення власних рецептів.
* Збереження улюблених страв у «Вибране».
* Можливість планувати харчування через календар
